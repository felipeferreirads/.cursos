| O que é erro absoluto? | A diferença entre o valor calculado e o valor exato (ou de referência): erro = \|valor aproximado − valor exato\|. |
| O que é erro relativo e por que é geralmente mais informativo que erro absoluto? | Erro absoluto dividido pelo valor exato. É mais informativo porque compara o erro ao tamanho da grandeza — um erro de 0,1°C é irrelevante em 1000°C, mas enorme em 0,3°C. |
| Por que, em praticamente qualquer linguagem de programação, a conta 0,1 + 0,2 não devolve exatamente 0,3? | Porque o computador guarda números em base binária usando ponto flutuante (quantidade finita de dígitos). Em binário, 0,1 vira uma dízima infinita, então é arredondado; cada número já chega arredondado, e a soma herda essas diferenças pequenas. |
| O que é ponto flutuante? | O jeito como um computador guarda números decimais na memória, com uma quantidade finita de dígitos. A maioria dos números reais não cabe exatamente nesse formato. |
| O que é erro de arredondamento? | O erro que nasce de representar um número com dígitos finitos, quando o valor exato precisaria de infinitos (ou mais dígitos que o formato guarda). |
| O que é erro de truncamento? | O erro que nasce de substituir um processo exato (muitas vezes infinito ou contínuo) por uma aproximação finita. Exemplo: parar uma soma infinita depois de poucos termos. |
| {{Erro de arredondamento}} é sobre representar números com dígitos finitos; {{erro de truncamento}} é sobre parar um processo infinito. | Erro de arredondamento, erro de truncamento |
| O que é cancelamento catastrófico? | Subtrair dois números muito próximos entre si preserva poucos dígitos significativos do resultado, mesmo que cada entrada fosse precisa. O erro relativo do resultado dispara. |
| Qual é um exemplo geológico comum de cancelamento catastrófico? | Calcular a idade de uma amostra a partir da razão entre um isótopo radiogênico acumulado e um isótopo original, quando as duas quantidades medidas são muito parecidas — a subtração preserva poucos dígitos confiáveis. |
| O que é condicionamento de um problema matemático? | Uma propriedade do problema (independente do método usado): um problema bem condicionado faz pequenas mudanças na entrada gerarem pequenas mudanças na saída; um mal condicionado faz o oposto. |
| Qual é um exemplo geológico clássico de cálculo mal condicionado? | Calcular o gradiente geotérmico a partir de duas medidas de temperatura em profundidades muito próximas — o denominador (diferença de profundidade) fica pequeno, amplificando qualquer erro de leitura do termômetro. |
| Dobrar a precisão (usar mais dígitos) resolve um problema mal condicionado? Por quê? | Não. Reduz o erro de arredondamento, mas um problema mal condicionado continua amplificando a incerteza de entrada, não importa quantos dígitos o cálculo carregue. |
| O que é um sistema linear? | Um conjunto de equações onde cada incógnita aparece apenas multiplicada por um número (nunca elevada a potência, nem dentro de seno/log), cuja solução é o conjunto de valores que satisfaz todas as equações ao mesmo tempo. |
| Cite um exemplo de sistema linear em geoquímica. | Balanço de massa de mistura de fontes: conhecidas a composição química da mistura final e de cada área-fonte, as frações de cada fonte no sedimento saem de um sistema linear (uma equação por elemento traçador). |
| O que é eliminação de Gauss? | Método direto que resolve um sistema em duas etapas: (1) escalonamento — usa-se a primeira equação para eliminar a primeira incógnita de todas as abaixo, depois a segunda, etc., até sobrar uma equação com uma incógnita; (2) substituição regressiva — resolve-se essa última e volta-se até a primeira. |
| O que é pivô na eliminação de Gauss? | O coeficiente usado em cada etapa para zerar os coeficientes abaixo dele numa mesma coluna. Se um pivô for muito pequeno (perto de zero), dividir por ele amplifica qualquer erro de arredondamento. |
| O que é pivotamento parcial? | Reordenação das equações a cada etapa para usar, como pivô, o maior coeficiente disponível na coluna. Não muda a solução, só evita amplificar erro numérico ao longo do processo. |
| O que é método iterativo para resolver sistemas lineares? | Método que parte de um palpite inicial e o refina, repetição após repetição, até o resultado parar de mudar de forma significativa. Nunca dá a resposta exata 'de uma vez', mas se aproxima dela. |
| O que é método de Gauss-Seidel? | Um método iterativo para sistemas lineares: em cada repetição, recalcula cada incógnita usando os valores mais recentes já disponíveis das outras. |
| Qual é a condição que garante a convergência de Gauss-Seidel? | Dominância diagonal: o coeficiente da diagonal de cada equação é maior, em valor absoluto, que a soma dos demais coeficientes daquela equação. |
| O que é uma matriz mal condicionada? | Um sistema em que pequenas mudanças nos coeficientes ou nos termos independentes produzem mudanças grandes e desproporcionais na solução — quase sempre porque as equações são quase redundantes entre si. |
| {{Eliminação de Gauss}} é um método {{direto}}; {{Gauss-Seidel}} é um método {{iterativo}}. | direto, iterativo |
| O que é encontrar um zero (ou raiz) de uma função? | Encontrar o valor de x tal que f(x) = 0. Muitas perguntas científicas recaem nisso: 'a que profundidade a temperatura atinge 100°C?' é encontrar o zero de (T(x) − 100). |
| Qual é a diferença entre métodos de bracketing e métodos abertos para encontrar zeros? | Bracketing: começam com dois pontos que já envolvem o zero (um com f>0, outro com f<0) e o reduzem progressivamente. Abertos: começam com um palpite inicial e usam derivadas para refinar, sem exigir bracketing. |
| O que é método da bisseção? | Um método de bracketing: a cada iteração, calcula-se o ponto meio entre os dois extremos do intervalo, avalia-se o sinal de f nesse meio, e descarta-se a metade que não contém o zero. Repete até o intervalo ser pequeno demais. |
| O que é método de Newton-Raphson? | Um método aberto: parte-se de um palpite inicial x₀ e usa-se a derivada da função para refinar, com a fórmula x_(n+1) = x_n − f(x_n) / f'(x_n), repetindo até convergir. Converge rápido, mas exige calcular a derivada. |
| Qual é uma desvantagem do método de Newton-Raphson? | Exige calcular (ou estimar) a derivada da função; se a derivada for pequena perto da raiz (função muito plana), o método fica lento ou diverge. |
| {{Bisseção}} é garantida de convergir; {{Newton-Raphson}} converge mais rápido, mas pode {{não convergir}} se o palpite inicial for ruim. | garantida de convergir, não convergir |
| Qual é a diferença entre interpolação e extrapolação? | Interpolação: estimar o valor de uma função entre dois pontos conhecidos. Extrapolação: estimar fora do intervalo dos dados conhecidos. Extrapolação é muito menos confiável. |
| O que é interpolação polinomial de Lagrange? | Um método que passa um polinômio exatamente pelos pontos dados; o polinômio produzido permite calcular valores em qualquer ponto entre eles. |
| Por que polinômios de grau muito alto para interpolação podem gerar oscilações indesejadas? | Fenômeno de Runge: um polinômio de grau muito alto se oscila perto das extremidades do intervalo, criando picos e vales que não estão nos dados originais. |
| O que é spline cúbica? | Uma interpolação que usa polinômios de baixo grau (cúbico) em cada intervalo entre pontos, em vez de um único polinômio de grau alto. Evita o fenômeno de Runge e dá curvas suaves. |
| Qual é a diferença entre interpolação (passa pelos pontos) e ajuste de curva (minimiza erro)? | Interpolação passa exatamente pelos pontos dados; ajuste minimiza o erro total entre a curva ajustada e os pontos, permitindo que a curva não passe exatamente por nenhum deles (útil quando há ruído nos dados). |
| O que é método dos mínimos quadrados? | Um método de ajuste de curva que encontra a curva (geralmente uma reta ou polinômio) que minimiza a soma dos quadrados das diferenças verticais entre a curva e os pontos dados. |
| Qual é o propósito da integração numérica? | Calcular a integral definida de uma função (a área sob a curva) quando não há antiderivada analítica ou quando a função é conhecida apenas em pontos discretos. |
| O que é regra do trapézio para integração numérica? | Aproxima a área sob uma curva como a soma de trapézios em intervalos pequenos. Quanto menor o intervalo, melhor a aproximação. É um método de baixa ordem, mas simples. |
| O que é erro de truncamento na integração numérica? | O erro que nasce de usar um número finito de intervalos (ou passos) onde caberiam infinitos. Quanto menor o intervalo, menor o erro de truncamento, mas maior o número de operações. |
| Qual é um exemplo geológico de integração numérica? | Calcular a massa de uma coluna de rocha integrando a densidade com a profundidade, quando a densidade varia de forma complexa e não se tem uma fórmula analítica. |
| {{A regra do trapézio}} usa aproximação de {{primeiro grau}} (linear) para cada intervalo. | primeiro grau |
| O que é uma equação diferencial ordinária (EDO)? | Uma equação que relaciona uma função desconhecida y(x) com suas derivadas (dy/dx, d²y/dx², etc.). Muitos fenômenos geológicos (fluxo de água, propagação de calor) são descritos por EDOs. |
| Qual é a diferença entre uma EDO de primeira ordem e uma de segunda ordem? | EDO de primeira ordem: envolve dy/dx. EDO de segunda ordem: envolve d²y/dx². Segunda ordem é mais complexa e geralmente precisa de duas condições iniciais. |
| O que é o método de Euler para resolver EDOs numericamente? | Um método simples: começa-se num ponto inicial (x₀, y₀) e usa-se a derivada (a inclinação) para dar um passo pequeno e estimar o próximo ponto, repetindo até o ponto final desejado. |
| Por que o método de Euler é menos preciso que outros métodos de passos múltiplos (como Runge-Kutta)? | Porque usa apenas a derivada no início de cada passo; métodos de passos múltiplos usam a derivada em vários pontos do intervalo, capturando melhor a curvatura da função. |
| Qual é um exemplo geológico de problema descrito por uma EDO? | Propagação de calor numa rocha (equação de difusão térmica): dT/dt = α × d²T/dx², onde α é a difusividade térmica. |
| {{O método de Euler}} é {{de primeira ordem}} em acurácia; {{Runge-Kutta}} é {{de quarta ordem}} (muito mais preciso). | de primeira ordem, de quarta ordem |
