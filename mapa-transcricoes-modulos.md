# Mapa: transcrições do YouTube → módulos do curso Geologia e Gemologia

Correspondência entre as 158 transcrições baixadas em `Transcricoes/` e os módulos
de `curso-geologia-gemologia/`. Uso pretendido: quando o `gerador-de-aula` for
escrever ou revisar uma aula de um módulo abaixo, pode consultar as transcrições
listadas como fonte extra de exemplos/explicações — não para copiar texto, só
para enriquecer analogias e checar se algum ângulo de explicação vale a pena
incorporar. Fontes normativas (livros-texto, IMA, USGS etc.) continuam sendo a
base para verificação factual; transcrição de vídeo não é fonte de auditoria.

Este arquivo não foi criado dentro da pasta do curso de propósito, para não
colidir com a sessão que está gerando o módulo 17 no momento. Depois, vale
referenciar este caminho no `_contexto.md` do curso.
